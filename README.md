## 🚀 Featured Projects

### 🧠 RAG-Powered Knowledge AI API

A backend application that allows users to query their own documents using natural language through a **Retrieval-Augmented Generation (RAG)** pipeline.

The system converts documents into vector embeddings, stores them in a vector database and retrieves relevant information before generating an AI response.

**What I implemented:**

- Developed REST API endpoints using **FastAPI**
- Generated vector embeddings from custom documents
- Implemented semantic similarity search
- Stored and retrieved embeddings using **ChromaDB**
- Integrated locally hosted AI models using **Ollama**
- Built a Retrieval-Augmented Generation pipeline to provide relevant context to the LLM
- Developed an API architecture separating knowledge-base creation from user queries

**Technologies:**

`Python` `FastAPI` `ChromaDB` `Ollama` `REST APIs` `Vector Embeddings` `RAG`
